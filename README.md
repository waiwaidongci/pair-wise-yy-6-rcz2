# 烟料配胶与成型复核台

墨锭试磨室扩改而成，负责烟料配胶登记、质量门限与成型放行复核。

运行：

```bash
npm start
```

访问 `http://localhost:3037`。数据保存在 `data/smoke-glue-review.json`。

端到端验证（会写入测试数据，执行前删除该数据文件即可重新播种）：

```bash
node server.js &      # 终端 1
node test-e2e.mjs     # 终端 2：29 项规则用例
```

## 模块划分

- `server.js` —— 请求入口：HTTP 路由、参数接收与页面。
- `rules.js` —— 配胶规则：绑定校验、调胶缸占用、筛余/灰分门限、双人双测放行、调整失效留档、并发幂等、列表与统计口径。
- `store.js` —— 记录存储：JSON 文件读写、原子写入与写队列串行化。

## 业务规则

1. 每次配胶必须绑定一种烟料批次、一个调胶缸和一个胶液批次，并登记筛余率、灰分、胶液粘度。
2. 同一调胶缸在配胶未完成（待复核 / 复核未过）前再次提交返回 `409 vat_busy`，且不落库。
3. 筛余率超过 3% 或灰分超过 0.8%：登记后直接「退回筛料」，不得进入成型。
4. 配胶后由两人各测一次粘度，两次都在 25±2 秒且操作人不同才放行「可成型」；第二次不达标为「复核未过」，可申请重新复核。
5. 调整烟料或胶液批次会让旧放行立即失效并回到待复核；旧结论写入 `history` 留档，不计入可成型列表。
6. 重复或并发提交（同缸且登记内容完全一致）沿用首次结果（HTTP 200），不产生新记录。
7. 列表、统计和刷新共用同一份存储记录与同一套状态口径。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/batches` | 配胶记录列表（含可成型标记与留档数） |
| GET | `/api/stats` | 按状态统计，含可成型数量 |
| POST | `/api/batches` | 配胶登记（409 见规则 2；重复提交返回首次记录） |
| POST | `/api/batches/:id/measurements` | 提交一次粘度测量（同操作人 / 已完成均 409） |
| POST | `/api/batches/:id/recheck` | 复核未过后申请重新复核 |
| PATCH | `/api/batches/:id` | 调整烟料/胶液批次或订正登记指标 |
