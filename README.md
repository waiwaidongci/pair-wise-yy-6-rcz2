# 烟料配胶与成型复核台

由墨锭试磨室扩展而来，负责烟料配胶登记、双人粘度复核与成型放行。

## 运行

```bash
npm start
```

访问 `http://localhost:3037`。数据保存在 `data/glue-review.json`。

## 测试

```bash
npm test
```

## 业务规则

- 每次配胶绑定一种烟料批次、一个调胶缸和一个胶液批次，并登记烟料筛余率、灰分和胶液粘度。
- 同一调胶缸有未完成（待复核）的配胶时，再次提交返回 409 且不落库。
- 筛余率超过 3% 或灰分超过 0.8% 的批次只能退回筛料，不得进入成型复核。
- 配胶后由两人各测一次粘度，两次都在 25±2 秒且操作人不同才放行进入可成型。
- 调整烟料或胶液批次后，旧放行立即失效并回到待复核；旧结论留档于历史，不计入可成型列表。
- 重复或并发提交（同一 requestId）沿用首次结果，不重复落库。

## 模块划分

- `server.js` — 请求入口：HTTP 路由、请求解析与页面渲染。
- `src/rules.js` — 配胶规则：校验、状态流转、双人复核放行与批次调整。
- `src/store.js` — 记录存储：数据加载、内存缓存与串行落盘。

## API

- `GET /api/batches` 配胶批次列表
- `POST /api/batches` 提交配胶（可带 `requestId` 幂等键）
- `GET /api/batches/:id` 批次详情
- `POST /api/batches/:id/checks` 粘度复核（`operator`、`seconds`）
- `PATCH /api/batches/:id` 调整烟料/胶液批次
- `GET /api/stats` 状态统计（待复核 / 可成型 / 退回筛料）
